# IslandTime

A Minecraft Fabric mod for Hypixel SkyBlock that tracks island time, minion fuel/profit per fuel day, item stats, and more. Includes Discord alerts and a configuration GUI.

## Features

- **Island Time Tracking** — Tracks time spent on your private island with daily history
- **Fuel Day Tracker** — Tracks minion fuel and profit per real 24h fuel-day via a dedicated GUI (`/it fueldays` or `/it fueltime`). Placing a stack of fuel across a batch of minions (e.g. 4 each) creates that many entries immediately — one currently ticking down, the rest future/queued days already carrying their share of the auto-detected minion count and estimated fuel cost — bucketed by each physical minion's queued fuel-cycle number so refueling a full set in sequence still records one shared next cycle, rather than splitting counts just because the GUIs were opened at different times. Refueling while fuel is active continues directly into the next 24h period; after fuel runs out, a new refuel starts from its actual fueling time and does not reuse the old expiry. Fuel-slot updates settle before counting a stack change, so server synchronization cannot split one insertion into multiple false fuel events. Each fuel-day gets its own "fuel day up" Discord alert the moment IT runs out (not just once, when the entire queued batch finally finishes), so the next queued day is already ticking by by the time you're pinged about the one that just ended. Each row/entry is titled with its day's actual start and end time (`DD/MM/YY HH:mm - DD/MM/YY HH:mm`), and a "Total Profit" widget in the top-right corner sums the final profit of every tracked day (supports up to the billions, e.g. `1.234B`). Each physical minion is identified by the permanent `uuid` of a minion upgrade in its upgrade slots (e.g. a Flycatcher) — upgrade items keep the same uuid forever, unlike the minion head, Enchanted Hoppers and other GUI items, which are regenerated with a fresh uuid (and a fresh `timestamp`, which is how they are filtered out) every time the menu is opened. Minions with no usable upgrade uuid fall back to the previous scheme — the armor stand's position and worn armor (not its entity UUID, which resets on server reload, and deliberately not whatever the stand is holding, since Hypixel gives each minion a randomly chosen sword every time it loads in, which silently changed the key on every rejoin) — and a minion already tracked that way is migrated onto its upgrade uuid, keeping all of its active and queued fuel-days, the first time its GUI is opened. Fuel-days saved under one of those older, sword-dependent keys are re-attached by block position (which holds exactly one minion) the first time the minion is opened, so nothing stranded by a sword re-roll is lost. Either way, fueling many minions in one sitting is tracked as that many distinct minions instead of collapsing into one. Supports placing full stacks of fuel at once (each unit queues an additional 24h fuel-day), auto-estimates each day's total fuel cost from a locked per-minion recipe price using Bazaar buy-order prices (the full Epic/medium Inferno Minion Fuel recipe cost: 25x Sulphuric Coal + 3x Very Crude Gabagool + 6x the cheapest of all five distillates + 2x Inferno Fuel Block, with a manual total-cost override). Use `/it fuelcost` or `/it fuelcost NUMBER` for a live full breakdown of all five distillate buy-order prices and the selected cheapest ingredient. The per-minion price is snapshotted once per fuel cohort/batch, existing automatic records retain their saved prices, and historical costs only change when you manually change the minion count or fuel cost; each day's total scales with its effective minion count (including manual count overrides), and re-fueling the same batch later never changes an already-recorded day's price — tracks mob-kill coins/day from a configurable 100%-AFK baseline scaled by that day's full-day AFK% (so coins accumulate steadily over the day, while the displayed AFK% itself is live — showing progress against time elapsed so far while a day is still in progress, rather than instantly looking tiny), and auto-tracks Crude Gabagool collected via Hypixel's in-game "[Sacks]" chat messages — including while a message-hiding mod like SkyHanni's "Sack Change Hider" is enabled, since the packet is read directly rather than from the visible chat log — (with a manual override, and a manually-entered sell price, for full profit-per-day tracking). The GUI's live values refresh once per second rather than every frame. Rows are color-graded red→yellow→green by AFK% and every field — including a manual minion-count override for when lag desyncs auto-detection — is directly editable, with minion-count, gabagool-amount, and fuel-cost override fields all accepting either an absolute value or a `+`/`-` prefixed delta (e.g. `+100000` or `-20000`) to adjust the auto-tracked value instead of replacing it. Start/end timestamps are editable in `dd/MM/yy HH:mm` format; changing an active or queued day moves later queued days with it. Future/queued days that haven't started yet show a condensed row (just minion count and fuel cost — everything else genuinely hasn't happened yet) and fill in normally once their cycle begins
- The MoulConfig **Default Gabagool Price** persists across fuel days and is applied only to the current day when it has not been manually overridden in the Fuel Day Tracker. AFK percentages for an active manually corrected cycle use the elapsed time since its edited start (and may exceed 100% if the start is shifted forward); once the cycle ends, the complete edited duration is used. `/it fuelcost` fetches a fresh Bazaar snapshot, while automatic fuel records keep their locked price from the cohort start.
- **Item Stat Tracking** — Monitors a tracked item's `stats_book` value and alerts if it stops increasing or goes missing
- **Discord Webhook Alerts** — Sends notifications for island absence, tracked item issues, disconnects, composter running empty (or about to), an item evolving (see Evolution Alerts), when a minion's queued fuel-days run out (repeats until you empty your sacks, since sack storage caps mean AFKing further gains nothing), and New Year's Celebration cakes (with a dedicated configurable webhook URL, configurable 5/15/30-minute reminders, and a final 5-minute warning)
- **Chat Relay** — Bridges island chat to/from Discord via a companion bot (outbound webhook + inbound localhost polling)
- **Backpack Preview** — Hover over a backpack to see its contents in an overlay; press Shift to inspect
- **Favourite GUI** — Save and view container snapshots (e.g. minion layouts) as read-only overlays
- **Island Player Tracking** — Detects when visitors leave your island with optional chat/Discord notifications
- **Show Hidden Tooltips** — Reveals tooltips on items that have `hide_tooltip` set (e.g. GUI filler panes)
- **PPG Display** — Shows Price Per Gabagool in the Very Crude Gabagool sell offer menu
- **Ghost Command** — Client-side block removal with `/it ghost`
- **Composter Alerts** — Tracks your Garden composter the way SkyHanni does (stored organic matter, fuel and time left from the `Composter` tab widget — the right-click Composter menu is read as a second source for the stored amounts — plus your Composter Speed / Cost Reduction levels from the Composter Upgrades menu) to estimate when it runs empty, then sends a Discord alert when it does and, optionally, a warning a configurable number of minutes beforehand (Composter config category, 10 minutes by default, 0 to disable). Uses the main Discord webhook and ping ID. Enable the Composter tab widget (`/widget`) and open the Composter Upgrades menu once so the mod knows your upgrade levels; `/it composter` shows what it currently knows, and `/it composter debug` (or the Copy Debug Info button) copies the tab list and last Composter menu contents to your clipboard if the composter is not being found
- **Evolution Alerts** — Sends one Discord alert (main webhook and ping ID) for every `EVOLUTION! Your <item> has evolved!` chat message, e.g. when your Rosewater Flask evolves. One chat message produces exactly one alert, with no repeats. Toggle under Chat Alerts in the MoulConfig GUI
- **Keep Resource Pack** — Caches the Hypixel SkyBlock resource pack locally and keeps it active everywhere (even outside Hypixel), skipping re-download if unchanged. Whenever Hypixel offers a newer pack than the cached one, the new pack is downloaded and swapped in (replacing the old copy in your enabled packs, both for the running game and for the next launch) instead of silently staying on the old version
- **Component Display** — Shows specified item components (e.g. `id`, `color`) at the bottom of tooltips in dark gray
- **Player List** — Scrollable GUI (`/it players`) to manage a list of players with quick party/invite buttons, editable notes, and head skin display. Also mirrors recent chat to the left of the list; shift + right-click a mirrored line — or hover it and press the configurable **Copy Chat Message Key** (default `C`, toggle and key under Player List in the MoulConfig GUI; ignored while typing in the search box) — to copy its full raw component structure (text and hover text, including every sibling) to the clipboard, with a brief "Copied" confirmation — a diagnostic aid for reporting chat-parsing bugs and for capturing the exact text of a message you want an alert for
- **Sign Helpers** — Adds paste buttons to the sign edit screen with configurable pre-set text per line
- **WAILA (What Am I Looking At)** — Inspect any targeted block or entity with `/it waila`. Blocks show block ID, position, state properties, tile entity data, skull textures, and SkyBlock custom IDs. Entities show their full info: entity type, name, entity ID, UUID, position, size, flags, tags, riding relationships, health, equipment and held/framed items (with SkyBlock IDs and head texture hashes), and full NBT. Entities that vanilla's crosshair can't target — marker armor stands, dropped items, display entities and the like — are found by looking at them too and are labelled "untargetable"; a targetable entity under the crosshair always takes priority. Blocks and entities beyond normal reach work too: WAILA casts a ray from where you are aiming (up to a configurable range, 128 blocks by default) and inspects the first thing it hits, so blocks hide entities behind them. Bind a key in the **WAILA** settings category to run it without typing the command (unbound by default) Both come with `[+ Add ... to Highlighter]` buttons — for entities, one adds the entity ID and another adds the entity name
- **Highlights** — Multi-entry block and entity highlight system with a dedicated GUI (`/it highlights`). Each entry has its own target (block ID, `entity:` plus any registered entity ID such as `entity:item_frame`, `entity:glow_item_frame`, or `entity:armor_stand`, optionally with a case-insensitive name filter such as `entity:armor_stand[name=Sparkling Critter]` (or `entity:*[name=Sparkling Critter]` to match any entity type by name), `sb:` SkyBlock ID, or `skull:` texture hash), color, range, intensity, through-walls toggle, and optional area filter. Quickly add highlights from WAILA results or via `/it highlight add`
- **Critter Safari Tracker** — On-screen widget listing the Critter Safari critters you have **not** caught yet this run (grouped by Forest/Cavern/Icy/Haunted biome) under a centered `caught/total` counter, so the list shrinks as you work through all 37 and you can see at a glance what is left. Catches are read from the `CAPTURE!` and `LOOT SHARE!` chat messages (including `SPARKLING` catches and the Hideyho "You found" variant); a caught critter flashes green and fades off the list over a second, and a critter that breaks out (`The Gimmiegold escaped your Critter Capsule!`) is shown in red until you land it. Optional announcements report each biome as you clear it (`Forest done (1m 12.7s)`, and `All done (1m 12.7s)` for the one that finishes the run) to party chat via `/pchat`, or only to your own chat as a local `[IslandTime]` message when that is turned off; timers start when the Safari ticket is handed in. The "Forest Minus Macaw" option reports `Forest done minus Macaw` / `All done minus Macaw` while Macaw is missing, then sends corrected `Forest done` / `All done` messages if Macaw is caught later. Saying `!missing` in public or party chat while inside the Safari replies in party chat with the uncaught creatures grouped as `Forest(Foxtrot, Macaw), Cavern(...)`; the response is capped at 200 characters and ends with `(and more...)` when needed. The tracker resets when the Safari Manager starts a new run — both the party line (`[NPC] Safari Manager: Looks good to me. Have fun out there!`) and the solo line (`[NPC] Safari Manager: I already saw your ticket, so you're free to go.`). Only rendered while you are inside the Safari, using the same tab-list area detection as Block Highlight (matched by keyword, so the shortened `Safari` area name and the biome sub-areas all count; this gate can be turned off if detection ever fails). The move screen also shows the area name currently detected, so mismatches are easy to spot. Toggle it, drag it anywhere on screen and scroll to resize it from the Critter Safari config category or `/it critters`. Also includes a **Sparkling Alert**: when a `SPARKLING` critter (the variant that awards a bonus Rainbow Feather) spawns near you, an XP pling plays once and a through-walls tracer line plus a large floating `SPARKLING` label mark it out. The alert, its sound, the tracer, the tracer color and the name tag are configurable under the Critter Safari category
- **Copy Skin** — Copy the skin texture of a targeted player head block to clipboard with `/it copyskin`, or copy from a skull item in any inventory/GUI by pressing a configurable keybind (default: `V`). Preserves transparency. The keybind and toggle are configurable in the MoulConfig GUI under Misc
- **Aging Items** — Compare profit per hour for all levelling items (Bottle of Jyrre, Dark Cacao Truffle, Discrite, Moby-Duck, Not Very Moldy Bread, Rosewater Flask) using live Bazaar prices. Configure time-bag and inventory slot counts for estimated hourly income. Add or remove custom item pairs with `/it agingItems add/remove`
- **Cookie Profit** — Compare profit per bit from spending Booster Cookie bits on Kismet Feathers, Magma Buckets, and Plasma Buckets using live Bazaar prices. Accounts for material costs (enchanted lava buckets) on crafted items. Configure your bits-per-cookie in the MoulConfig GUI
- **MoulConfig GUI** — All settings accessible from a single GUI opened with `/it` (alias: `/islandtime`)

## Installation

1. Requires **Minecraft 26.1** with **Fabric Loader** and **Fabric API**
2. Download the latest release from the [Releases](../../releases) page
3. Place the JAR in your `.minecraft/mods` folder

## Configuration

Settings are saved in the `config` folder as `islandtime*.txt` files (and `fuel_days.json` for the fuel day tracker). Never share these publicly — they contain your Discord webhook URL.

Minion identities (which permanent upgrade uuid belongs to which tracked minion) are kept in `config/IslandTime/minion_identities.json`. It is written automatically the first time each minion's GUI is opened and is shared by both the real and test fuel-day files; deleting it only costs the mod its memory of past minion identities, which it rebuilds as each minion is opened again. The file holds one record per minion — its canonical id, the minion's name, its position, and the upgrade uuids that resolve to it — with the armor-stand equipment string shared in an `armorTypes` table at the top rather than repeated in full on every entry. Files written by earlier versions used a flat alias list instead; those are detected and converted automatically on the next launch, with nothing lost.

The Fuel Day Tracker has a "Use Test Data File" toggle (in the Fuel Cycles config category) that redirects all fuel/profit tracking to a separate `fuel_days_test.json` file instead of your real `fuel_days.json`, so you can safely experiment without risking your actual tracked history. Toggling it reloads the Fuel Day Tracker GUI's data from whichever file is now active.

Inside `fuel_days.json`, each minion's fuel state is one record in a `minions` list (its key, name, position, fuel expiry and queued units), and each day lists the short refs (`m1`, `m2`, ...) of the minions counted toward it rather than repeating their full keys. Earlier versions stored this as three separate maps keyed by the full minion key, which repeated each key — up to ~210 characters for a coordinate-based one — hundreds of times at the top of the file. Both layouts load, so existing saves, test files and older backups are read unchanged and are rewritten in the new layout on the next save.
